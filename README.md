# Therapy Hub (with Cash Course)

A practice site for speech-language therapy sessions, for adolescents through older adults. It covers memory, language (aphasia), speech (dysarthria), swallowing (dysphagia), reasoning, thinking and planning (executive function and attention), and money skills (**Cash Course**). It runs entirely in the browser and is hosted free on GitHub Pages. There are no accounts and no server, and data never leaves the device.

See [PLAN.md](PLAN.md) for the roadmap.

## Areas and tasks

| Area | Task | What it practices |
|---|---|---|
| 🧠 Memory | **Spaced Retrieval** | One important fact (room number, call button, a safety step) recalled at 30 s → 1 → 2 → 4 → 8 → 16 → 32 min. A miss gives the answer, then goes back one interval. A banner on every page says when it's time to ask, so you can do other tasks in between. |
| | **Word List** | 3–10 words (with pictures, words only, or heard only) → filler wait → free recall (clinician checks off) → category cues → pick them out of a list. Delayed recall of the last list later in the session. |
| | **Story Recall** | Voicemails, appointment reminders, recipes, notices and news, read or heard. Questions after, with "look again" as a cue. Can be asked again later (delayed). |
| | **Remember the Number** | Room numbers, door codes, phone numbers. Forward or backward. Gets longer after a right answer, shorter after two misses. |
| | **Matching Pairs** | Card-flip visual memory, 3, 6 or 8 pairs. |
| | **Mental Workout** | Hold 3–5 words in mind, then say them backward, in ABC order or smallest to biggest. Or unscramble a sentence. |
| | **Chunk It** | Break phone, order and account numbers into chunks, then recall them. |
| | **Names and Faces** | Meet 2–4 people whose names start like their jobs (Doctor Dana), then recall the names after a wait. |
| 💬 Language | **Name It** | Picture naming with a cueing hierarchy: meaning → first sound → "say it with me". |
| | **Point to It** | Hear or read a word, tap the picture. Foils get closer at higher levels (same category, same first sound). |
| | **Follow Directions** | 1-step → 2–3 step → "before/after", "if/if not" and "except" directions on a picture board. |
| | **Yes or No** | Simple facts → comparisons, reversals and word meanings. |
| | **Finish the Sentence** | "Salt and ___" → everyday sentences → less predictable ones. |
| | **Name Things in a Category** | 30/60/90-second timer and a +1 counter. Goal set per category. |
| | **What Am I?** | Name the word from 2 clues. Cues: first sound → pick one of two → model. |
| | **Word Links** | Same meaning, opposite, and words that go together. |
| | **Category Builder** | Name the group, or pick the one that fits a group. |
| | **Read and Do** | Written directions on a board of shapes and numbers ("Tap every number bigger than 5"). |
| 🗣️ Speech | **Loud & Clear** | Live loudness meter with a target line (set from the patient's own voice), long "ah" timing, loud phrases. |
| | **Say It Clearly** | Words → phrases → sentences, mostly functional. Record and listen back. Clinician rates understood / partly / not understood. |
| | **Pacing Board** | Tap a box per word at a set pace, with a demo. Shows the words-per-minute. Plus a 5-second pa-ta-ka warm-up with a count. |
| 🥄 Swallowing | **My Exercises** | Only the exercises you prescribe (effortful swallow, Masako, Shaker, Mendelsohn, CTAR, supraglottic, tongue press, jaw opening), with your reps, holds and sets. Big hold countdown, rest timer, reps logged. |
| | **My Swallow Plan** | Diet, strategies and notes on a printable bedside card. |
| | **Remember My Strategies** | Recall practice for the patient's own strategies, plus general safety scenarios. |
| 🧩 Reasoning | **Odd One Out, Analogies, Safety & Problem Solving, Read Between the Lines, What's Wrong Here?** | Multiple choice with a hint → narrowed to two → the answer and why. |
| | **Deductions** | Clue puzzles for 2–4 people ("Ann does not drink tea"). Every puzzle has exactly one answer. Help shows the clues as a ✓/✗ grid. |
| 📋 Thinking & Planning | **Put It in Order** | Steps of everyday tasks (3–7). Right steps stay; the rest go back. |
| | **Pill Organizer** | Read 1–3 labels ("twice a day", "Mon/Wed/Fri", "bedtime") and fill a weekly pill box. Wrong boxes are outlined. |
| | **Read the Calendar** | Questions about a week of appointments, with time math and schedule clashes. |
| | **Find Them All** | Cancellation/visual scanning. Results split into **missed on the left vs. right**, useful for neglect. |
| | **Switch It Up** | Connect 1-2-3… or switch 1-A-2-B… Time and wrong taps logged. |
| | **Clocks and Time** | Read an analog clock, set one, and work out how long or what time it will be. |
| | **Daily Planner** | Questions about a day of plans: start and end times, what's next, free time, clashes. |
| 💵 Money & Community | **Cash Course** | Everything below, unchanged. |
| | **Checkbook** | Write a check amount in words, total a deposit slip (with cash back), balance a check register. Difficulty follows the Money price setting. |

All content is original. Pictures are emoji, so there's nothing to license and it all works offline.

**How the patient answers** (memory, language, swallowing): **spoken** (you tap ✓ / ✗ and can "move on" if they don't get it), **choose** from options, or **typed** (case, typos, plurals and "a/the" are forgiven).

**Patients:** Clinician → **Patients** lists everyone on the device by initials. Each patient has their own settings, areas, levels, spaced-retrieval targets and swallow plan. Turn off areas a patient doesn't use. With only one area on, the app opens straight to it. A patient with only Money on sees the original Cash Course. A device that already had Cash Course keeps opening to Cash Course: its existing settings became patient 1 with only Money turned on.

**Microphone:** off by default. When on, it's used only for the meter and record-and-listen-back. Sound is processed in the browser, never saved or sent.

## Cash Course (Money & Community)

| Section | Activity | What he practices |
|---|---|---|
| 🍽️ Eat out | **McDoogles, Taco Smell, Chipoodle, Domin-Oops, Starducks** | Order (kiosk or menu board) → add up the order → (tax) → pay → work out the change → receipt. Chipoodle and Domin-Oops have build-your-own items with paid add-ons (guac, toppings). Starducks has Tall/Grande/Quacki sizes and add-ins. |
| | **Grapplebee's** | Sit-down restaurant: the server brings the check, he picks or works out the tip, then pays |
| | **DoorDosh** | Order delivery at higher app prices → add up the delivery fee, service fee, small order fee and tip → "How much extra does delivery cost?" |
| 🛒 Shop online | **Fal-Mart, Amazoom, LEGGO Store, Bass Bro Shops** | Search and browse → product page → cart → subtotal → pick delivery → "Is shipping free?" → total with shipping/tax → how much is left on the gift card → place order. Bass Bro Shops is hunting and fishing gear (no weapons or ammo). |
| 💪 Money skills | **Quick Change** | "The price is $7.39. You pay with $20. How much change?" |
| | **Check the Change** | Work out the change, then check what the cashier hands back, and learn what to say if it's wrong |
| | **Saving Up** | Pick a goal (LEGGO Star Warz sets, trail camera, deer license…): "How much more do you need?" and "How many weeks?" |
| | **Can I Afford It?** | "You have $10. It costs $11.29. Can you buy it?" Quick yes/no, then how much is left or how much more he'd need |
| | **Chaise Bank** | A debit account: purchases and deposits, "What's your balance now?", and cards declined when there isn't enough |
| | **Better Deal?** | Two stores, one item: $ off, buy-one-get-one, "3 for $10" (sometimes a trap), % off. Pick the better deal, then "How much do you save?" |
| | **Read the Receipt** | Find a price, the tax, the total, the change, or count the items. At higher levels, check the receipt against the bag for a planted mistake |
| | **Spot the Scam** | Texts, emails, DMs and pop-ups: real or scam? Afterward it shows the red flags and what to do |

**Budget mode** (clinician setting): "You have $15 to spend." After the total, he answers "Do you have enough?" If not, he goes back and puts something back. In stores, the gift card becomes the budget.

With **Order type → Task**, restaurants give an **order card** and stores give a **shopping list**, sometimes including "the cheapest ___", so he has to compare prices.

Every problem has three help levels: **Hint → More help → Answer**. Each problem is logged with the highest help level used, the number of tries, the time taken and whether he used the calculator.

## Clinician settings

Click **🔒 Clinician** at the bottom-left of any page. The first time, you'll create a 4-digit PIN. One PIN covers every patient on the device.

- **Patients:** add, switch and remove patients (initials only)
- **Areas and levels:** which areas each patient sees, how they answer, and a level (1–3) per area. Memory: list length, wait before recall, spaced-retrieval targets. Speech: microphone, loudness line, pacing speed. Swallowing: exercises with reps/holds/sets, strategies, diet and notes for the card.

- **Ordering and shopping:** price difficulty (whole dollars → cents), free choice vs. task (order card / shopping list), kiosk vs. menu board, running total on/off, gift card amount for online stores
- **Tax:** on/off, rate (default 7.25%), whether the app or the client works out the tax
- **Paying:** app pays with the next bill up or a $20, client pays the next dollar up, or client picks bills from a wallet
- **Change help:** count up like a cashier (number line) or column subtraction with borrowing shown
- **Help:** how many help levels, start with help showing (errorless), wait before help unlocks, hint after a wrong answer
- **Calculator:** phone-style calculator on/off. Its use is recorded.
- **Display:** read-aloud buttons, large text, high contrast
- **Say your order** (restaurants): after ordering, he practices saying it: "Hi, can I get a Grande Caffè Latte with oat milk, please?"
- **Scam pop-ups** (stores): once per visit, a fake pop-up appears. Closing it is right, and it's logged either way.
- **Budget and tips:** budget off, a fixed amount, or different each order; tip mode at Grapplebee's (pick 15/18/20%, or work out 15% or 20%)
- **This visit:** a start/stop visit timer for the current patient (tap a time to fix it), then this visit's results, the share done independently, results by skill, and every problem. Starting a visit starts the practice numbers over. **Start visit** is also on each row of the Patients tab.
- **Visit times:** every visit on a day, for all patients, with start, stop and minutes. Minutes are counted between the clock times shown (10:02 to 10:39 is 37 minutes). Shows minutes per patient and the day's total, lets you add a visit you forgot to time, and exports CSV.
- **Orientation:** mark the patient oriented, oriented with a cue, or not oriented to person, place, time and situation. Shows Oriented ×0–4 (and ×N with cues), the latest check, each area over time, and every check. Exports CSV.
- **Progress:** a chart of the share done independently each day (by skill or all), and a mastery check per skill. The mastery rule is adjustable, e.g. 80% for 3 sessions in a row with at least 5 problems.
- **Homework:** printable worksheets (menu math, make change, can I afford it, better deal) with an answer key on a separate page
- **Prices:** change any price or name to match your area. Saved on that device; the backup in Data carries them to another device.
- **Data:** export CSV for notes, download/import a JSON backup (includes price edits, visit times and orientation checks), delete data

The PIN only keeps settings away from the client. It isn't real security. All data lives in the browser's local storage on that device, so data from his phone and from your laptop stay separate. Use the backup export to move data between devices.

**Privacy:** use initials or a nickname, never a full name.

## Editing menus, products and prices

- Restaurant menus: [src/data/restaurants/](src/data/restaurants/), one file per restaurant
- Store products: [src/data/stores/](src/data/stores/). LEGGO and Star Warz items are shared in `toys.ts`, and each store sets its own price.
- Saving Up goals: the top of [src/modules/SavingUp.tsx](src/modules/SavingUp.tsx)

Prices are in cents (`599` = $5.99). Change names or prices, then commit and push, and the site updates in a minute or two. For quick changes on one device, use **Clinician → Prices** instead.

## Publishing to GitHub Pages

1. Create a new repository on GitHub (for example `cash-course`). GitHub Pages on a free account needs a **public** repository. The site holds no client data, so that's fine.
2. Push this folder to the repository's `main` branch.
3. On GitHub, go to **Settings → Pages**, and under **Build and deployment → Source** choose **GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` runs the tests, builds and publishes. The site will be at `https://<your-username>.github.io/<repo-name>/`.

On his phone, open the site and use **Share → Add to Home Screen** (iPhone) or **⋮ → Add to Home screen** (Android) so it opens like an app.

**Offline:** after the site has been opened once with internet, it keeps working without Wi-Fi. When you're online again it picks up updates (sometimes it takes a second reload).
